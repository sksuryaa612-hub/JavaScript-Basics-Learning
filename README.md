
# 📘 JavaScript Basics – Operators & Grading System

This repository contains two simple JavaScript programs to learn basic operators and conditions in an easy way.

---

## 🔢 1. Assignment Operators Program

This program shows how assignment operators work in JavaScript. It explains how a variable value can be changed step by step using operators like `+=`, `-=`, `*=`, `/=`, `%=` and `**=`. This helps you understand how values are updated while the program runs.

---

## 🎓 2. Grading System Program

This program calculates final marks by adding bonus marks and then finds the grade based on the final marks. It checks if the marks are between 0 and 100 using logical operators. Based on the result, it gives grades like A, B, C, F, or INVALID. It also shows pass or fail using a ternary operator and gives a remark using a switch statement.

---

## 🚀 Overall Learning Outcome

This project helps you understand how JavaScript operators, conditions, and decision-making work together in simple real-life programs.
